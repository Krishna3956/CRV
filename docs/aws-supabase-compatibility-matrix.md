# TrackMCP self-hosted Supabase compatibility matrix

Status: discovery baseline, 2026-11-01. This document records what is known from the repository and authenticated, read-only project inspection. It is not a migration sign-off.

## Migration complexity

Overall complexity is **HIGH** for a safe production migration, even though the application integration change is **LOW**. The repository is centralized around the Supabase SDK, but authentication continuity, OAuth reconfiguration, 45 migrations, RLS, restricted-source exports, and rollback consistency are high-impact concerns. The safest path is an isolated staging restore followed by a controlled write freeze and one-way cutover with a documented rollback decision.

## Known source limits

The hosted project currently reports 54 Auth users and is restricted for Free-plan egress overage. Exact database bytes, object inventory, and historical traffic are not available from the read-only inspection performed so far. Those measurements are required before choosing storage size, backup cadence, and capacity.
